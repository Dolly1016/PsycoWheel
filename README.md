# キチガイ風車 (PsycoWheel)

[Nebula on the Ship](https://github.com/Dolly1016/Nebula) 用のアドオンです。
マップ内を動き回るキチガイ風車を追加します。"認識"されないように、こっそり見続けましょう。

## 遊び方

### 通常モード
オプションでキチガイ風車をオンにすると、タスクフェーズが始まるたびにキチガイ風車が出現します。
キチガイ風車は一度プレイヤーを"認識"すると、緊急会議が始まるまで追いかけ続けます。プレイヤーをキルしたキチガイ風車は消滅し、次の緊急会議が終わると復活します。

キチガイ風車を見ると恩恵を得られます。
- クルーメイト: 50回見るごとにタスクが1つ完了します。
- キルボタンを持つ非クルーメイト: 10回見るごとにキルクールダウンが5秒短縮します。

### キチガイ風車モード
制限時間内にキチガイ風車を見た回数を競う専用ゲームモードです。
緊急会議は開けず、死体も通報できません。時間とともにキチガイ風車が増えていき、ときどきドアがランダムに閉まります。

## 導入方法
- **マーケットプレイスから**: NoSのマーケットプレイスで「キチガイ風車」を検索して有効にしてください。
- **手動で**: [Releases](https://github.com/Dolly1016/PsycoWheel/releases/latest) から `PsycoWheel.zip` をダウンロードし、Among Usのフォルダの `Addons` に置いてください。

## リポジトリの構成
このリポジトリの中身(`README.md` と `.gitignore` を除く)をそのままzipにしたものがアドオンです。

- `addon.meta`: アドオンの情報
- `Scripts/`: スクリプト(NoSが起動時にコンパイルします)
- `Resources/`: 画像
- `Language/`: 翻訳
